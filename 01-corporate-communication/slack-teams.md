# Slack / Teams

## Rules of thumb
- **Don't just say "Hi"** — ask your question in the same message.
- Use **threads** to keep channels clean.
- Use **channels over DMs** for team-relevant questions (others learn too).
- Add context: links, error messages, screenshots, what you tried.
- Set status when OOO or in focus time.

## Bad vs good

**Bad:**
> hi
> are you there?

**Good:**
> Hi Rohan, quick question on the auth service — I'm getting a 401 on `/refresh` in staging even with a valid token. I've checked the env vars. Any idea if something changed recently? Logs: <link>

## Common reactions
| Emoji | Usually means |
|-------|---------------|
| 👀 | Looking into it |
| ✅ | Done / acknowledged |
| 👍 | Okay / agreed |
| 🙏 | Thanks |

## Useful phrases
- "Tagging @Sneha for visibility."
- "Moving this to a thread."
- "Will check and update here."
- "Resolved — root cause was X. Closing the loop."
