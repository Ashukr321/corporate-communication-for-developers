# Emails

## Structure
1. **Subject** — specific: `[Action Required] Review payment API changes by Fri`
2. **Greeting** — "Hi Team," / "Hi Neha,"
3. **Context** — one line on why you're writing
4. **Body** — details, bullets if more than two points
5. **Ask** — what you need, from whom, by when
6. **Closing** — "Thanks," / "Best regards,"

## Useful openers
- "Hope you're doing well."
- "Following up on our discussion yesterday..."
- "As discussed in today's call..."

## Useful closers
- "Please let me know if you have any questions."
- "Happy to jump on a call if that's easier."
- "Looking forward to your feedback."

## Template

```
Subject: [FYI] Checkout service deployment on 12 Oct

Hi Team,

We're deploying checkout-service v2.4.0 to production on 12 Oct at 10 PM IST.

- Expected downtime: none (rolling deploy)
- Changes: new coupon validation, bug fixes for cart sync
- Rollback plan: revert to v2.3.1

Please let me know if you have any concerns before EOD Thursday.

Thanks,
Ashutosh
```

## Avoid
- "Please do the needful" (vague) → state the exact action.
- "Revert back" → just "reply".
- Walls of text → use bullets.
