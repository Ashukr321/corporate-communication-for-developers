# Giving Updates

A good update answers: **status, progress, risk, next step, ETA.**

## Status words
| Word | Meaning |
|------|---------|
| On track | Will meet the deadline |
| At risk | Might miss the deadline |
| Blocked | Can't proceed without something |
| In progress / WIP | Currently working on it |
| In review | PR raised, awaiting review |
| Done | Merged / deployed / verified |

## Template
> **Task:** Search filters (JIRA-231)
> **Status:** In review
> **Done:** API integration, UI, unit tests
> **Pending:** Review comments, QA
> **Risk:** None
> **ETA:** Tomorrow EOD

## When you're late — say it early
> "Quick heads-up: the export feature is taking longer than expected because the CSV library doesn't support streaming. I now estimate Thursday instead of Tuesday. I'll update if anything changes."
