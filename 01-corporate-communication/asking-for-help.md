# Asking for Help

## Before asking
Spend a reasonable time (15–60 min) trying yourself, then ask. Don't stay stuck for a whole day.

## Good question format
1. **What** you're trying to do
2. **What** happened (error, logs, screenshot)
3. **What** you've already tried
4. **Specific** ask

## Example
> "Hi Arjun, I'm trying to run the order-service locally but it fails on startup with `ECONNREFUSED 5432`. I've checked Docker is running and the `.env` matches the README. Do I need a separate DB seed step? Happy to pair for 10 minutes if you have time."

## Phrases
- "Do you have a few minutes to help me with...?"
- "Could you point me in the right direction?"
- "Is there any documentation I can refer to?"
- "Would you be open to a quick pairing session?"
- "Thanks, that unblocked me!"
