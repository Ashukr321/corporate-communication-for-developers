# Daily Office Terms

| Term | Meaning | Example |
|------|---------|---------|
| Sync | Short meeting to align | "Let's have a quick sync on the API contract." |
| Loop in | Add someone to a conversation | "Looping in @Priya from QA." |
| Circle back | Return to a topic later | "Let's circle back on this after the release." |
| Bandwidth | Available time/capacity | "I don't have bandwidth this sprint." |
| Heads-up | Advance warning | "Heads-up: staging will be down at 3 PM." |
| Take it offline | Discuss separately, not in this meeting | "Let's take this offline to save time." |
| Touch base | Check in briefly | "I'll touch base with you tomorrow." |
| On my plate | My current workload | "I have two tickets on my plate." |
| Ping | Send a quick message | "Ping me once the PR is up." |
| OOO | Out of office | "I'll be OOO on Friday." |
| Stakeholder | Anyone affected by / interested in the work | "We need stakeholder sign-off." |
| Sign-off | Formal approval | "Waiting for PM sign-off." |
| Hand off | Transfer ownership of work | "I'll hand off the ticket before my leave." |
| Deep dive | Detailed investigation | "Let's do a deep dive into the latency spike." |
| Low-hanging fruit | Easy, quick win | "Fixing the lint errors is low-hanging fruit." |
| Align | Agree on direction | "Let's align on the approach before coding." |
| Action item | Concrete task from a discussion | "Action item: Rahul to update the docs." |
