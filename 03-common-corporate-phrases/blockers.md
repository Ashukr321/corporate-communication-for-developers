# Blockers

A **blocker** is anything that stops you from making progress. Raise it **early**, with **what you need** and **from whom**.

## Phrases
- "I'm blocked on the backend dependency."
- "I'm blocked until I get access to the staging DB."
- "This is blocking the release."
- "Partially blocked — I can continue with the UI using mock data."
- "Is anyone able to help unblock this?"
- "Unblocked now, thanks to @Kiran."

## How to raise a blocker
> "I'm blocked on **[what]** because **[why]**. I need **[specific thing]** from **[person/team]**. Meanwhile, I'll **[workaround / other task]**."

**Example:**
> "I'm blocked on the payment integration because the sandbox keys have expired. I need new keys from the DevOps team. Meanwhile, I'll write unit tests for the order module."

## Related
