# Priorities

## Terms
| Term | Meaning |
|------|---------|
| Priority (P0/P1/P2/P3) | P0 = drop everything, P3 = nice to have |
| Deprioritize | Move lower in importance |
| Backlog | List of pending work |
| Must-have / Nice-to-have | Required / optional |
| Quick win | Small effort, visible value |
| Critical path | Tasks that directly decide the delivery date |

## Phrases
- "What's the priority on this?"
- "Should I pause the current task and pick this up?"
- "I have X and Y on my plate — which one should I prioritize?"
- "This is a P0, I'm jumping on it now."
- "Can we move this to the next sprint?"
- "This is a nice-to-have; let's add it to the backlog."

## Saying no politely
- "I'd love to help, but I'm committed to X for this sprint. Can we check with the lead on priority?"
- "If I take this up, Y will slip by two days. Is that okay?"
