# Timelines

## Terms
| Term | Meaning |
|------|---------|
| ETA | Estimated time of arrival/completion |
| Deadline | Fixed date it must be done by |
| Deliverable | Concrete output you hand over |
| Milestone | Significant checkpoint in a project |
| EOD / EOW | End of day / end of week |
| Buffer | Extra time added for risk |
| Slip | Get delayed ("the date slipped") |
| Scope creep | Requirements growing after work started |

## Giving estimates
- "My rough estimate is 3 days, including testing."
- "I'll be able to give a better estimate after the spike."
- "ETA is tomorrow EOD, assuming the API is ready."
- "This is a ballpark — I'll refine it once I dig in."

## When a timeline is at risk
- "I want to flag early that this might slip by a day because..."
- "To hit the deadline, we could cut X from scope."
- "The new requirement adds scope — can we revisit the timeline?"

## Tip
Always give estimates with **assumptions** ("assuming design is final") so you're not blamed when they change.
