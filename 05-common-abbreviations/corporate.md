# Corporate Abbreviations

| Abbr | Full form | Example |
|------|-----------|---------|
| ETA | Estimated Time of Arrival | "ETA for the fix is 4 PM." |
| EOD | End Of Day | "I'll share it by EOD." |
| EOW | End Of Week | "Target is EOW." |
| COB | Close Of Business | Same as EOD |
| TBD | To Be Decided / Determined | "Release date is TBD." |
| TBA | To Be Announced | "Venue TBA." |
| FYI | For Your Information | "FYI — staging is down." |
| ASAP | As Soon As Possible | Use sparingly; give a real time if you can |
| WIP | Work In Progress | "Still WIP." |
| OOO | Out Of Office | "OOO tomorrow." |
| WFH | Work From Home | |
| PTO | Paid Time Off | |
| AFAIK | As Far As I Know | |
| IIRC | If I Remember Correctly | |
| IMO / IMHO | In My (Humble) Opinion | |
| TL;DR | Too Long; Didn't Read (summary) | "TL;DR: we need one more day." |
| AKA | Also Known As | |
| N/A | Not Applicable | |
| 1:1 | One-on-one meeting | Usually with your manager |
| AOB | Any Other Business | End of meeting agenda |
| KT | Knowledge Transfer | "KT session before handover." |
| POC | Point Of Contact | "Neha is the POC for billing." |
| SPOC | Single Point Of Contact | |
| RACI | Responsible, Accountable, Consulted, Informed | Ownership matrix |

## Project communication words (not abbreviations, but used just as often)

| Word | Meaning |
|------|---------|
| Blocker | Something stopping progress |
| Dependency | Something your work relies on |
| Priority | How important/urgent it is |
| Deadline | Fixed due date |
| Deliverable | Concrete output to hand over |
| Milestone | Major checkpoint |
| Scope creep | Requirements growing mid-project |
| Action item | Task assigned from a meeting |
| Follow-up | Checking back on something pending |
