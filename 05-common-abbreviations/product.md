# Product Abbreviations

| Abbr | Full form | Meaning |
|------|-----------|---------|
| PM | Product Manager (or Project Manager) | Owns what gets built |
| PO | Product Owner | Owns the backlog (Scrum) |
| PRD | Product Requirements Document | What to build and why |
| MVP | Minimum Viable Product | Smallest version worth shipping |
| AC | Acceptance Criteria | Conditions for "done" |
| DoD / DoR | Definition of Done / Ready | Team agreements on ticket state |
| UX / UI | User Experience / User Interface | |
| KPI | Key Performance Indicator | Metric that tracks success |
| OKR | Objectives and Key Results | Goal-setting framework |
| A/B test | — | Compare two variants with real users |
| DAU / MAU | Daily / Monthly Active Users | |
| CTR | Click-Through Rate | |
| GA | General Availability | Released to all users |
| Beta | — | Pre-release for limited users |
| GTM | Go-To-Market | Launch plan |
| B2B / B2C | Business-to-Business / Consumer | |
