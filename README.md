## How SDEs actually say it

The fastest way to sound professional: replace the casual version with the corporate one.

| Casual | Corporate / SDE |
|--------|-----------------|
| I don't know. | I'll look into it and get back to you. |
| It doesn't work. | I'm currently seeing an issue with... |
| Backend didn't give me the API. | I'm blocked on the backend dependency. |
| I'll do it later. | I'll pick this up after completing X. |
| There is a bug. | I've identified an issue in... |
| I need more time. | I may need additional time to complete this safely. |
| Why did you change this? | Could you help me understand the reasoning behind this change? |
| This code is bad. | I think we could improve this implementation by... |
| It's finished. | The implementation is complete and the PR is ready for review. |
| I made a mistake. | I missed an edge case — I've raised a fix. |
| That's not my job. | I think X's team owns this; let me loop them in. |
| I'm confused. | Could you clarify the expected behavior for... |
| This will take forever. | This is larger in scope than expected; I'd estimate X days. |
| Can't do it. | That's not feasible within the current timeline, but we could... |
| Your code broke prod. | We're seeing a regression after the latest deploy; investigating. |
