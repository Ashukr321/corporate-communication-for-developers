# Client Communication — Real Examples

## Weekly status email
```
Subject: Weekly Update — Project Phoenix (Week 38)

Hi Sarah,

Here's this week's update:

Completed
- User profile module (live on staging)
- Payment gateway integration

In progress
- Order tracking (ETA: 30 Sep)

- Approval on the checkout designs by Friday.

Ashutosh
```

## Explaining a delay
> "We've found that the third-party shipping API has stricter rate limits than documented. To avoid failures for your users, we're adding a queue, which moves the delivery by 3 days to 4 Oct. The rest of the scope is on track."

## Responding to a new request (scope change)
> "Thanks for the suggestion — it makes sense. Since it's outside the agreed scope, we'll estimate the effort and share the impact on the timeline by tomorrow."

## Explaining a bug in non-technical words
| Technical | Client-friendly |
|-----------|-----------------|
| "Race condition in the cart service." | "In rare cases, adding items quickly could show the wrong total. We've fixed it." |
| "We had a regression after the deploy." | "A recent update caused an issue with login, which we resolved within 20 minutes." |
| "The API is rate limited." | "The external service limits how many requests we can send, so we're adding a safeguard." |

## Saying "I don't know"
> "Good question — I'd like to confirm with the team so I give you an accurate answer. I'll get back to you by tomorrow."
