# Manager Communication — Real Examples

## Flagging a delay early
> "Hi Priya, a quick heads-up: the export feature is taking longer than planned because the library doesn't support large files. I now expect to finish by Thursday instead of Tuesday. Want me to cut PDF export from this release to keep the date?"

## Asking for clarity on priorities
> "I have the search bug (P1) and the dashboard feature on my plate. Which one should I prioritize this week?"

## Requesting leave
> "Hi Amit, I'd like to take leave on 3–4 Oct for a family function. My tickets will be in review by then, and I'll hand off anything pending to Rohit."

## Admitting a mistake
> "I missed the null check in yesterday's release, which caused the profile page error. I've raised a hotfix (PR #210) and added a test for it. Sorry about that."

## Asking for feedback (1:1)
> "Is there anything I could be doing better in terms of code quality or communication?"
> "What would you expect from me to be ready for the next level?"

## Asking for help without sounding stuck
> "I've been investigating the memory leak for a day. I've ruled out X and Y. Would it be okay to pull in someone from the platform team for a quick look?"

## Pushing back on unrealistic timelines
> "I understand the urgency. Realistically this needs 5 days including testing. If we need it in 3, we could ship without the admin panel and add it next sprint. Which works better?"
